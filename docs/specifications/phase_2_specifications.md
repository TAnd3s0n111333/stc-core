## Executive Summary
The objective for phase 2 was to develop the Resource and Logistics Planner (RLP) including its multi objective integer linear programming optimization (MOILP). Moreover, agent and labor logic will be included, along with corrected resource logic, and a basic physics engine to check the compatibility of models in a selected environment. A basic CLI will be added to allow the user to remove specific modules and select a chosen mission.
